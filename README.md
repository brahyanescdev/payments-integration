# Tienda — checkout de pago con tarjeta de crédito

Aplicación de onboarding de pago con tarjeta de crédito contra una pasarela
colombiana en modo sandbox: catálogo con stock, captura de datos de tarjeta y
entrega, resumen, resultado de la transacción y actualización de inventario.

Monorepo con SPA en React y API en Nest.js. En construcción por etapas; cada
funcionalidad entra por pull request con sus tests y su evidencia visual.
